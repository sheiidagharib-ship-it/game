# دوز آنلاین 🎮

بازی دوز (Tic-Tac-Toe) دو نفره آنلاین با رابط کاربری فارسی و راست‌به‌چپ.

## نحوه بازی
1. صفحه بازی را باز کنید.
2. نفر اول «ساخت اتاق جدید» را می‌زند و کد اتاق یا لینک دعوت را برای دوستش می‌فرستد.
3. نفر دوم کد را وارد می‌کند یا روی لینک می‌زند و «ورود» را انتخاب می‌کند.

اتصال بین دو بازیکن مستقیم و با WebRTC (کتابخانه PeerJS) برقرار می‌شود.
حالت دو نفره روی یک سیستم هم بدون اینترنت در دسترس است.
